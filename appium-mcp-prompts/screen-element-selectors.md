# Analyze Screens Elements and Selectors - Android

Using the Appium MCP Server (#mcp-appium ), execute the following workflow on the Android **Scriptlab** app:

**Note:**
* Install the app from apps/android folder.
* Appium Server is already running. DO NOT START APPIUM AGAIN.


## Objectives: Analyze Screens Elements and Selectors

1. **App Launch**
  - Launch the Scriptlab Android application from the apps folder using #mcp-appium
  - Verify successful app initialization


2. **Login Screen Analysis**
  - Capture and analyze all UI elements on the login screen
  - Identify element selectors (ID, XPath, Accessibility ID, etc.)
  - Note element properties (type, visibility, interactability)


3. **Authentication**
  - Login using following credentials:
    - Username: `scriptlab`
    - Password: `scriptlab123`
  - Confirm successful navigation to Home screen


4. **Home Screen Analysis**
  - Capture and analyze all UI elements on the home screen
  - Identify element selectors (ID, XPath, Accessibility ID, etc.)
  - Note element properties (type, visibility, interactability)


5. **Navigate through all available screens**
  - Navigate through all available screens and features of the app.
  - Capture and analyze all UI elements on each screen.
  - Note element properties (type, visibility, interactability)


6. **Documentation**
  - Create a markdown file named **`mcp-appium-exploration/android-elements.md`** containing:
    - Separate tables for Login and Home screens
    - Columns: Element Name, Selector Type, Selector Value, Element Type, Additional Properties
    - Clear section headers and formatting
    - Any relevant observations or notes about element behavior
